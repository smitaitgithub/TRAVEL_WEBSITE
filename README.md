🌍 US Trip Registration Form – GCET Greater Noida
This project is a web-based Trip Registration Form built using HTML, CSS, PHP, and MySQL.
It allows users to submit their personal details for a college trip, and the data is securely stored in a MySQL database.

📌 Project Description
The US Trip Registration Form collects student information such as name, age, gender, email, phone number, and additional details.
When the form is submitted, PHP processes the request and inserts the data into a MySQL table.
A confirmation message is shown to the user after successful submission.
This project demonstrates full-stack concepts including frontend design, backend scripting, form handling, and database connectivity.
